# VAG IMMO Editor

Профессиональный инструмент для чтения и редактирования прошивок иммобилайзеров VAG Group (Volkswagen, Audi, Skoda, Seat).

## Возможности

- **Чтение PIN-кода** - автоматическое извлечение PIN-кода иммобилайзера (5 или 7 знаков)
- **Просмотр одометра** - отображение текущего пробега автомобиля
- **Редактирование опций** - включение/отключение различных настроек иммобилайзера
- **Поддержка чипов** - работа с EEPROM 24LC64E (8KB), SN1413 1J0
- **Различные типы IMMO** - поддержка IMMO2, IMMO3, VDO, Motorola, NEC

## Стек технологий

- **C# 12** - современный язык программирования
- **WPF** - графический интерфейс Windows Presentation Foundation
- **.NET 8** - кроссплатформенная среда выполнения
- **BouncyCastle.Cryptography** - криптографические функции
- **CommunityToolkit.Mvvm** - MVVM фреймворк

## Сборка и запуск

### Требования

- .NET 8 SDK
- Windows 10/11 (для WPF)

### Команды сборки

```bash
# Восстановление зависимостей
dotnet restore

# Сборка проекта
dotnet build

# Запуск приложения
dotnet run

# Публикация релизной версии
dotnet publish -c Release -r win-x64 --self-contained
```

## Использование

1. **Открытие файла**: Нажмите "Открыть" или Ctrl+O для загрузки BIN файла
2. **Просмотр данных**: PIN-код, пробег и другая информация отобразятся автоматически
3. **Редактирование опций**: Выберите опцию в списке и нажмите "Применить"
4. **Сохранение**: Сохраните измененный файл через "Сохранить" или Ctrl+S

## Поддерживаемые форматы

- BIN файлы размером до 8KB (24LC64)
- Дампы EEPROM с приборных панелей VAG
- Прошивки иммобилайзеров SN1413 1J0

## Важные замечания

⚠️ **Предупреждение**: Используйте программу только на законных основаниях. Неправильное редактирование прошивки может привести к неработоспособности иммобилайзера.
