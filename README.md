# VAG IMMO Editor Pro

Профессиональное приложение для работы с прошивками иммобилайзеров VAG на чипе 24LC64 (8KB EEPROM).

## 🚀 Возможности

### Основные функции
- **Чтение PIN IMMO** - автоматическое извлечение PIN-кода (4-7 знаков) из BCD/ASCII формата
- **Показ одометра** - отображение текущего пробега автомобиля с корректным множителем
- **VIN номер** - чтение и редактирование 17-значного VIN
- **CRC проверка** - автоматическая валидация и пересчет контрольных сумм

### Поддерживаемые типы IMMO
| Тип | Производитель | Автомобили | PIN | CRC |
|-----|--------------|------------|-----|-----|
| IMMO2 | Early VAG | до 1998 | 4 ASCII | Нет |
| IMMO3 VDO | Siemens/VDO | A4/A6, Passat B5, Golf IV | 5 BCD | CRC16-CCITT |
| IMMO3 Motorola | Motorola | Golf IV, Seat, Skoda | 7 BCD | CRC16-Motorola |
| IMMO3 NEC | NEC | Audi, VW | 5 BCD | CRC16-CCITT |
| IMMO4 Kayaba | Kayaba | A8, Touareg, Cayenne | 7 BCD | CRC16-Motorola |

### Редактируемые опции
- ✅ Component Protection (защита компонентов)
- ✅ Learning Mode (режим обучения ключей)
- ✅ Immobilizer Active (статус иммобилайзера)
- ✅ Key Count (количество ключей)
- ✅ Country Code (код страны)

### Безопасность данных
- 🔒 Undo/Redo система с полной историей изменений
- 🔒 Валидация размера файла (256-8192 байт)
- 🔒 Проверка CRC при загрузке
- 🔒 Возврат копий массивов (не ссылок)
- 🔒 Защита от выхода за границы буфера

## 📖 Использование

### 1. Открытие BIN файла
1. Нажмите кнопку **"📂 Открыть"**
2. Выберите файл дампа EEPROM (*.bin)
3. Приложение автоматически определит тип IMMO и проверит CRC

### 2. Просмотр данных
- **PIN IMMO** - отображается в верхней панели
- **Одометр** - текущий пробег в км
- **VIN** - 17-значный идентификационный номер
- **CRC Status** - VALID ✓ или INVALID ✗

### 3. Редактирование опций
1. В списке "Опции иммобилайзера" найдите нужную опцию
2. Установите/снимите галочку
3. Изменение сразу применяется к данным

### 4. Изменение PIN/Пробега
```csharp
// Через интерфейс программы используйте соответствующие поля
// Или программно через ImmoParserService:
immoParser.UpdatePin("12345");
immoParser.UpdateMileage(150000);
```

### 5. Отмена/Повтор изменений
- **Undo (Ctrl+Z)** - отменить последнее изменение
- **Redo (Ctrl+Y)** - повторить отмененное изменение

### 6. Сохранение
1. Нажмите **"💾 Сохранить"**
2. Укажите путь для сохранения
3. CRC пересчитывается автоматически перед записью

## 🔐 Технические детали

### Алгоритмы CRC

**CRC-16/CCITT (VDO)**
```
Poly: 0x1021, Init: 0x0000
RefIn: false, RefOut: false, XorOut: 0x0000
```

**CRC-16/Motorola**
```
Poly: 0x8005, Init: 0x0000
RefIn: false, RefOut: false, XorOut: 0x0000
```

### Форматы данных

**BCD кодирование PIN:**
- Каждый байт содержит 2 цифры
- Старший ниббл = первая цифра, младший = вторая
- Заполнитель: 0xFF

**Пробег:**
- Хранится в BCD формате
- Множитель: x10 (для большинства типов)
- Порядок байт зависит от типа IMMO

### Карты памяти (смещения)

| Параметр | IMMO3 VDO | IMMO3 Motorola |
|----------|-----------|----------------|
| PIN | 0x1E0 (5 байт) | 0x1F0 (7 байт) |
| Пробег | 0x1D0 (4 байта) | 0x1C0 (4 байта) |
| VIN | 0x1B0 (17 байт) | 0x1A0 (17 байт) |
| CRC | 0x1FC (2 байта) | 0x1FE (2 байта) |
| Опции | 0x1F8 | 0x1F9 |

## ⚠️ Предупреждения

1. **Резервное копирование** - Всегда создавайте резервную копию оригинального дампа перед редактированием!
2. **Проверка CRC** - Если CRC INVALID, данные могут быть повреждены
3. **Совместимость** - Убедитесь, что тип IMMO определен правильно
4. **Ответственность** - Используйте на свой страх и риск. Автор не несет ответственности за поврежденное оборудование.
