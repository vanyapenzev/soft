# VAG EEPROM Editor - VDO/Continental IMMO4

Десктопное приложение на базе .NET 8 (WPF) для чтения, анализа и безопасного редактирования бинарных дампов EEPROM приборных панелей VAG с фокусом на платформу IMMO4 (5JA920810B VD1).

## Архитектура проекта

Проект разделен на логические модули (Namespaces):

```
/workspace
├── App.Models/          # Структуры данных, DTO, enum
├── App.Core/            # Бизнес-логика, парсеры, загрузчики
├── App.Crypto/          # Алгоритмы расшифровки и CRC
└── App.UI/              # WPF пользовательский интерфейс
```

## Структура модулей

### App.Models
- `DashboardData` - основная модель данных приборной панели
- `DumpType` - типы поддерживаемых дампов (24C32/24C64)
- `KeyInfo` - информация о ключах иммобилайзера
- `EditResult/EditOperation` - результаты операций редактирования

### App.Core
- `MemoryMap` - карта памяти EEPROM с адресами всех значимых данных
- `DumpLoaderService` - загрузка и валидация файлов
- `DataParserService` - парсинг VIN, пробега, IMMO данных
- `EditCommands` - паттерн Command для безопасного редактирования
- `VdoCrcCalculator` - пересчет контрольных сумм (CRC-16, XOR)

### App.Crypto
- `IImmoCryptoService` - интерфейс крипто-сервиса
- `VdoNecCryptoService` - расшифровка PIN, CS, MAC для IMMO4
- `ImmoDataFileService` - работа с внешними файлами ImmoData

### App.UI
- WPF приложение с современным интерфейсом
- Hex-редактор для просмотра дампа
- Панель информации о приборке
- Панель управления операциями

## Функциональные возможности

### Загрузка и валидация
- Поддержка файлов .bin размером 4096 (24C32) или 8192 (24C64) байт
- Автоматическая идентификация типа приборной панели по сигнатурам
- Поиск Part Number, VIN в дампе

### Парсинг данных
- **Одометр**: декодирование с учетом резервных копий и инверсии
- **VIN-код**: извлечение 17-значного номера кузова (ASCII)
- **IMMO данные**: статус, PIN (зашифрованный), CS (7 байт), MAC (4 байта)
- **Ключи**: информация о прописанных ключах (до 8 слотов)

### Безопасное редактирование
- **Изменение пробега**: запись нового значения + пересчет всех копий и CRC
- **IMMO OFF**: отключение иммобилайзера с проверкой совместимости
- **Защита от ошибок**: блокировка операций при неизвестной структуре дампа

### Контрольные суммы
- Пересчет XOR CRC для блока пробега
- Пересчет CRC-16 (полином 0x8005) для всего дампа
- Автоматическое обновление после каждой модификации

## Сборка и запуск

```bash
# Требуется .NET 8 SDK
dotnet restore
dotnet build --configuration Release

# Запуск (только Windows с WPF)
dotnet run --project App.UI
```

## Карта памяти (Memory Map)

| Смещение   | Данные                    | Размер |
|-----------|---------------------------|--------|
| 0x01F0    | Part Number               | 16     |
| 0x0200    | HW Version                | 8      |
| 0x0210    | SW Version                | 8      |
| 0x0500    | VIN                       | 17     |
| 0x0600    | IMMO Status               | 1      |
| 0x0610    | Encrypted PIN             | 5      |
| 0x0620    | Encrypted CS              | 7      |
| 0x0630    | Encrypted MAC             | 4      |
| 0x0700    | Keys (до 8 шт × 16 байт)  | 128    |
| 0x0A00    | Mileage Primary           | 4      |
| 0x0A10    | Mileage Backup 1          | 4      |
| 0x0A20    | Mileage Backup 2          | 4      |
| 0x1FE0    | Global CRC                | 2      |

## Важные примечания

⚠️ **Предупреждение о безопасности:**
- Все операции редактирования выполняйте только на резервных копиях
- IMMO OFF может привести к неработоспособности приборки при неправильном использовании
- Реальные алгоритмы шифрования требуют реверс-инжиниринга конкретной версии ПО

🔧 **Для полноценной работы требуется:**
- Тестовые дампы приборки 5JA920810B (минимум 5-10 образцов)
- Файлы ImmoData, полученные через OBD2 для расшифровки PIN/CS/MAC
- Дампы Flash процессора NEC для генерации crypto key
