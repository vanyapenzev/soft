# VAG IMMO Editor Pro

Профессиональный редактор EEPROM для комбинаций приборов VAG (24LC64, 24LC32, 24LC16).

## Возможности

### Чтение и парсинг данных
- **PIN Code IMMO** - автоматическое извлечение PIN-кода (5-7 знаков) из BCD/ASCII формата
- **Одометр** - чтение и коррекция пробега с поддержкой км/мили
- **VIN номер** - чтение и редактирование VIN
- **SKC (Secret Key Code)** - извлечение секретного ключа
- **ID транспондеров** - чтение ID зарегистрированных ключей

### Редактирование
- Изменение PIN кода
- Коррекция пробега
- Редактирование VIN
- Управление флагами:
  - Component Protection
  - Learning Mode
  - Immobilizer Active
- Количество ключей
- Код страны

### CRC и валидация
- Автоматический расчет CRC при сохранении
- Поддержка алгоритмов:
  - CRC-16/CCITT (VDO)
  - CRC-16/Motorola (IMMO3)
  - CRC-8 (IMMO2)
- Визуальная индикация статуса CRC

### Безопасность
- Undo/Redo система с полной историей изменений
- Валидация размера файла (256-8192 байт)
- Проверка границ массивов
- Возврат копий данных вместо ссылок
- Обработка исключений с понятными сообщениями

### Дополнительные функции
- Экспорт данных в JSON
- Сравнение двух дампов EEPROM
- Автоопределение типа иммобилайзера
- Поддержка карт памяти для разных типов комбинаций

## Системные требования

- Windows 10/11
- .NET 8.0 Runtime
- 100 MB свободного места

## Карты памяти (EEPROM Maps)

Каждая карта памяти содержит точные смещения для:
- PIN кода
- Пробега
- VIN номера
- SKC
- Транспондеров
- Флагов
- CRC

Пример карты для IMMO3 VDO:
```csharp
PinOffset = 0x1E0
MileageOffset = 0x1D0
VinOffset = 0x1F0
CrcOffset = 0x1FC
```

## Криптография

Поддерживаемые алгоритмы:
- **XOR** - простое шифрование для тестирования
- **DES-ECB** - для IMMO3 (VDO, Motorola)
- **AES-128-CBC** - для IMMO4 и современных систем
